## Thesis
As AI model capabilities grow exponentially, the primary bottleneck for developers has shifted from raw intelligence to infrastructure and reliability. To address this, Anthropic introduced Claude Managed Agents, a platform designed to handle the complexities of long-horizon, agentic workflows—such as security, context management, observability, and tool execution—allowing developers to move beyond simple prompting and build robust, autonomous systems that can reliably complete multi-step tasks.

## Key Points
*   **The Shift to Long-Horizon Tasks:** Modern AI agents are evolving from executing short, simple prompts to managing complex, multi-hour or multi-day workflows, necessitating a shift from basic prompting to a dedicated agentic runtime.
*   **Addressing Developer Challenges:** Research indicated that developers struggled significantly with context management, infrastructure concerns (security and credential management), and a lack of formal observability when building agents.
*   **Core Components of Managed Agents:** The platform provides a structured environment where developers define agents (configuration, prompts, tools) that operate within sessions, allowing for persistent environments, networking, and package management.
*   **Event-Driven Architecture:** The platform uses a comprehensive event topology categorized into four types—User, Agent, Session, and Span events—to provide transparency and allow developers to track the agent’s lifecycle and decision-making process.
*   **Practical Tooling:** Developers can get started using Claude Code (which includes a skill for building managed agents), a CLI for programmatic control, and various cookbooks for implementation guidance.
*   **Advanced Capabilities:** Recent updates to the platform include multi-agent orchestration (delegating tasks to other agents), "Outcomes" (allowing agents to iterate until they satisfy a predefined rubric), persistent memory, and a "dreaming" platform where agents can codify learnings to improve between runs.
*   **The "Inner" and "Outer" Loop:** The presenters demonstrated an efficient development cycle where an "inner loop" uses Outcomes to optimize performance autonomously, while an "outer loop" allows developers to provide feedback and use code agents to refine instructions and rubrics for subsequent sessions.
*   **Real-World Impact:** The platform was developed in partnership with companies like Asana and Notion, and it enables developers to build sophisticated systems, such as the "Boss Agent" demo, which autonomously optimized its own performance to reduce rendering time from 37 seconds to 10 seconds.
