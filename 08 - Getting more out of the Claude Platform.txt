## Thesis
The central argument of this session is that successfully deploying AI agents into production requires moving beyond simple proof-of-concepts to a disciplined approach of "context engineering" and cost optimization. By leveraging specific platform features—such as prompt caching, intelligent context management, and tiered model strategies—developers can significantly reduce latency and costs while maintaining high-level performance and reliability in long-running agentic workflows.

## Key Points
*   **Prompt Caching is Essential:** For long-running agents, prompt caching is the most critical optimization, offering a 90% discount on input tokens, reducing latency, and bypassing API rate limits for cached tokens.
*   **Tools for Optimization:** Developers should utilize the Claude console’s new prompt cache dashboard to monitor performance and leverage the "Claude Code" skill to automatically implement cache control markers.
*   **Context Engineering:** This discipline involves proactively managing what information enters the model's context window to prevent bloat and maintain intelligence.
*   **Tool Search Tool:** Instead of loading all tools upfront, this feature allows agents to defer loading tools until they are actually needed, which can reduce token usage and improve model focus.
*   **Programmatic Tool Calling:** By allowing the model to write Python code to extract only the necessary data from tool outputs, developers can avoid flooding the context window with extraneous information.
*   **Compaction:** For very long-running agents, compaction summarizes stale conversation turns, allowing the agent to maintain continuity without hitting context window limits.
*   **The Advisor Strategy:** To balance cost and performance, developers can pair a smaller, inexpensive model (like Sonnet) with a more powerful model (like Opus) that acts as an "advisor" to review work and provide guidance on complex tasks.
*   **Platform Evolution:** The speaker highlighted additional platform improvements, such as Workload Identity Federation (WIF) for security and the ANT CLI tool, which allows Claude to manage platform resources directly.
