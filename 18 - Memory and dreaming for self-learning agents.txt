## Thesis
Anthropic is introducing "Memory" and "Dreaming" as critical new primitives within their Managed Agents API to enable autonomous agents to achieve continuous self-learning and context management over long-horizon tasks. By modeling memory as a file system that agents can manage and update, and introducing "Dreaming"—an asynchronous process that synthesizes learnings across multiple agent sessions—Anthropic aims to help developers build more intelligent, efficient, and reliable multi-agent systems that evolve based on their collective experience.

## Key Points
*   **Evolution of Agent Primitives:** Anthropic has progressively released primitives like MCP (for tools/data), harnesses (like Claude Code), and Skills to help agents perform increasingly complex, long-running tasks.
*   **Memory as the Next Primitive:** Memory is introduced as the essential component for "self-learning" agents, allowing them to retain knowledge about task success criteria, common mistakes, and environment-specific data.
*   **File-System Based Design:** Memory in Managed Agents is modeled as a file system, allowing Claude to use familiar tools like `bash` and `grep` to organize, update, and manage its own memory structure autonomously.
*   **Enterprise-Grade Features:** To support production environments, the memory system includes permission scopes (read-only vs. read-write), optimistic concurrency controls, and detailed audit logs with version history and attribution metadata.
*   **Portable API:** The memory system is accessible via a standalone API, allowing developers to integrate their own pipelines for PII scanning, manual review, or cloning data into external systems without being locked into the platform.
*   **Introduction of "Dreaming":** Dreaming is a new research preview feature that runs as an asynchronous, out-of-band process to analyze patterns and mistakes across multiple agent sessions and automatically update the memory state.
*   **Benefits of Dreaming:** By operating outside the "hot path" of active tasks, Dreaming allows for large-scale, cross-agent learning and deduplication without adding latency to individual agent performance.
*   **Real-World Impact:** Early testing with partners like Rakuten and Harvey has shown significant improvements, including a 90% reduction in first-pass mistakes and a sixfold increase in task completion rates.
*   **Future Vision:** Anthropic views the combination of real-time Memory (for immediate task context) and Dreaming (for long-term knowledge curation) as the foundation for building sophisticated, scalable multi-agent systems that improve continuously over time.
